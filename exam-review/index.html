점검 전에 한글에서 맞춤법 검사를 먼저 하세요! 시험지 원안·채점기준표·답안지를 한글에서 열고 F8 키를 누르면(또는 [도구 → 맞춤법]) 사전 기반 맞춤법 검사가 실행됩니다. 이 앱은 사전에 없는 오타(예: 사가, 항기, 뚜강)를 다 찾지 못하므로, 오타는 한글 맞춤법 검사로 먼저 걸러 주세요.
더 안심하고 쓰려면 내 컴퓨터에 저장해서 쓰세요.이 화면은 파일 한 개로 되어 있습니다. 저장한 파일을 더블클릭하면 인터넷 주소 없이 내 컴퓨터에서 똑같이 열리고, 인터넷을 끊어도 그대로 점검됩니다.
✔ 지금 내 컴퓨터에 저장된 파일로 열려 있습니다. 주소창이 file:///로 시작하면 인터넷의 웹 페이지가 아니라 이 컴퓨터 안의 파일입니다.
시험 원안이 밖으로 나가지 않는지 직접 확인하는 방법
  1. 인터넷을 끊고 점검해 보기 — 노트북(와이파이)은 비행기 모드를 켜고, 데스크톱(랜선)은 랜선을 뽑으세요. 비행기 모드는 무선만 끄므로 랜선 연결은 끊기지 않습니다. 작업 표시줄 오른쪽 아래 네트워크 아이콘이 지구본(🌐) 모양으로 바뀌면 끊긴 것입니다. 이 상태에서도 점검이 끝까지 됩니다.
  2. 연결 기록 보기 — 이 화면에서 F12 → [네트워크(Network)] 탭을 연 채로 파일을 열고 점검해 보세요. 바깥으로 나가는 연결이 하나도 생기지 않습니다.
  3. 보안 설정 — 이 파일 맨 앞에 외부 연결을 모두 막는 보안 설정(CSP: connect-src 'none')이 들어 있어, 프로그램 안에서 보내려 해도 브라우저가 막습니다. 외부 라이브러리·글꼴·그림도 불러오지 않습니다.
  4. 저장되는 것 — 이 브라우저에는 체크리스트의 확인 표시만 저장됩니다. 시험 원안 내용은 창을 닫으면 사라집니다.
  5. 소스 공개 — 프로그램 전체가 이 파일 안에 그대로 들어 있어 누구나 열어 볼 수 있습니다(메모장으로 열거나 Ctrl+U).

점검할 파일 내 컴퓨터 안에서만 읽음

한글 파일은 HWP·HWPX 모두 그대로 열 수 있고, 문항정보표는 PDF(나이스에서 내려받은 것) 또는 XLSX로 열어 주세요. 시험지 원안만 있어도 점검할 수 있고, 나머지 파일은 연 만큼 배점을 대조합니다.

(이름에 ‘시간표’ → 시험시간표, ‘채점’·‘기준’ → 채점기준표, ‘답안지’ → 답안지, PDF·XLSX → 문항정보표, 나머지 → 시험지)

점검하는 내용

  • 오타: 자주 틀리는 맞춤법(싸인펜→사인펜 등), 띄어쓰기(할수 있다, 서술 하시오 등), ‘율/률’, 물음표 앞 빈칸, 닫히지 않은 배점 괄호, 오타 후보(문서 안에 여러 번 나오는 낱말과 모음 하나만 다른 낱말: 온도→온두) — 나머지 맞춤법은 한글 F8로 확인
  • 문구: 같은 낱말의 띄어쓰기 불일치(입자 모형/입자모형 — 띄어 쓴 곳과 붙여 쓴 곳의 문서·문항 표시), 단위 기호 혼용(℃/°C), 발문 끝 물음표 누락, 선지 마침표 혼용, 소문항 번호 표기 혼용
  • 편집: 그림 해상도, 등사 인쇄 시 어둡게 뭉개지는 그림(중간 밝기 영역, 구분이 사라지는 색), 선지 번호 기호(➀ 등) 혼용, 배점 괄호 형식 혼용
  • 점수: 배점 표기 누락, 소문항 합 = 문항 배점, 총점 100점, 시험지·채점기준표·답안지·문항정보표 배점 일치, 쉬운 문항 배점 > 어려운 문항 배점
  • 밑줄: 부정 표현(옳지 않은, 아닌 등)의 밑줄·굵게, ‘밑줄 친’ 발문인데 본문에 밑줄이 없는 경우
  • 표지: 표지의 선택형·서답형 문항 수 표기 = 원안 문항 수, 꼬리말 총 쪽수 표기(‘6-’의 6) = 원안 쪽수 (표지·머리말·꼬리말의 나머지 내용은 점검하지 않음)
  • 일정: 시험시간표를 넣으면 표지의 시험 날짜·교시가 시간표의 해당 학년·과목과 같은지 대조
  • 점검하지 않는 것: 정답·복수 정답, 사실 오류, 채점기준 내용, 발문 명확성, 학교 출제 유의사항(자료 지칭·기호 규칙), 운영 계획 대조는 선생님이 직접 검토해 주세요.
