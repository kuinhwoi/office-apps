# 출제 원안 자가검토 도우미 (exam-review)

정기시험 원안(HWPX)·서답형 채점기준표·서답형 답안지·문항정보표(PDF·XLSX)·시험시간표를 넣으면 점검 체크리스트를 만들어 주는 앱입니다.

## 꼭 지킬 것
- **인터넷에 연결하지 않고** 동작합니다. 외부 라이브러리·CDN을 쓰지 않고, 페이지 안의 보안 설정(CSP)으로 외부 연결을 막아 둡니다. 시험 원안이 밖으로 나가면 안 되기 때문입니다.
- 파일은 브라우저 안에서만 열고, 브라우저에는 체크 상태만 저장합니다.

## 점검 범위(선생님이 정한 것)
- 오타(사전 기반·문서 안 비슷한 낱말), 문구(띄어쓰기·단위 표기 통일), 편집(그림 해상도·등사 인쇄 미리보기), 점수(배점 대조·총점·소문항 합), 밑줄(부정 표현), 표지(문항 수·꼬리말 쪽수), 일정(시험시간표 날짜·교시)
- 빼기로 한 것: 정답·내용 판단, 학교 출제 유의사항(자료 지칭·기호), 운영 계획 대조, 글꼴·글자 크기, 낱말장, '이상 없음' 표
- 맞춤법은 한글 F8 검사로 하도록 화면에 안내합니다.

## 안심하고 쓰기(v1.6~)
- [내 컴퓨터에 저장해서 쓰기] 단추: 처음 불러온 화면(`PAGE_HTML`)을 그대로 HTML 파일로 저장. `file:` 주소로 열리면 단추 대신 "내 컴퓨터 파일로 열려 있음" 표시.
- 인터넷 상태 띠(`navigator.onLine`): 연결되면 노란 띠(와이파이는 비행기 모드, 랜선은 뽑기), 끊기면 초록 띠.
- '파일 넣기' 대신 '파일 열기'라고 씀(올린다는 오해 방지). '직접 확인하는 방법' 안내(F12 네트워크, CSP 등).

## 소스
- 이 폴더의 `index.html`은 빌드 결과(한 파일)입니다. 원본 소스는 선생님 컴퓨터의 `고사 원안 검토 앱\src` 폴더에 있고, 그 앱 폴더의 `build.ps1`로 합칩니다(공개 저장소라 소스 폴더 경로는 적지 않음).
- 버전: `src\app.js` 맨 위 `APP_VERSION`, `APP_DATE`.
