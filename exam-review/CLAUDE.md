# 출제 원안 자가검토 도우미 (exam-review)

정기시험 원안(HWP·HWPX)·서답형 채점기준표·서답형 답안지·문항정보표(PDF·XLSX)·시험시간표를 넣으면 점검 체크리스트를 만들어 주는 앱입니다.

## 꼭 지킬 것
- **인터넷에 연결하지 않고** 동작합니다. 외부 라이브러리·CDN을 쓰지 않고, 페이지 안의 보안 설정(CSP)으로 외부 연결을 막아 둡니다. 시험 원안이 밖으로 나가면 안 되기 때문입니다.
- 파일은 브라우저 안에서만 열고, 브라우저에는 체크 상태만 저장합니다.

## 점검 범위(선생님이 정한 것)
- 오타(사전 기반·문서 안 비슷한 낱말), 문구(띄어쓰기·단위 표기 통일), 편집(그림 해상도·등사 인쇄 미리보기), 점수(배점 대조·총점·소문항 합), 밑줄(부정 표현), 표지(문항 수·꼬리말 쪽수), 일정(시험시간표 날짜·교시)
- 빼기로 한 것: 정답·내용 판단, 학교 출제 유의사항(자료 지칭·기호), 운영 계획 대조, 글꼴·글자 크기, 낱말장, '이상 없음' 표
- 맞춤법은 한글 F8 검사로 하도록 화면에 안내합니다.

## 안심하고 쓰기(v1.6~)
- [내 컴퓨터에 저장해서 쓰기] 단추: 처음 불러온 화면(`PAGE_HTML`)을 그대로 HTML 파일로 저장. `file:` 주소로 열리면 단추 대신 "내 컴퓨터 파일로 열려 있음" 표시.
- 인터넷 상태 띠(`navigator.onLine`): 연결되면 노란 띠(와이파이는 비행기 모드, 랜선은 뽑기), 끊기면 초록 띠.
- '파일 넣기' 대신 '파일 열기'라고 씀(올린다는 오해 방지). '직접 확인하는 방법' 안내(F12 네트워크, CSP 등).

## 소스
- 이 폴더의 `index.html`은 빌드 결과(한 파일)입니다. 원본 소스는 선생님 컴퓨터의 `고사 원안 검토 앱\src` 폴더에 있고, 그 앱 폴더의 `build.ps1`로 합칩니다(공개 저장소라 소스 폴더 경로는 적지 않음).
- 버전: `src\app.js` 맨 위 `APP_VERSION`, `APP_DATE`.

## 파일 오류 안내(v1.8~)
- 파일을 못 읽으면 어느 파일(이름)·파일 안의 어느 부분인지와 해결 방법을 표시. 문서 암호 HWPX(manifest의 암호화 정보), 내용이 암호화된 문서(배포용·DRM), 통째로 잠긴 파일(DRM), 확장자만 바뀐 HWP·XLS를 구분해 안내.
- [내 컴퓨터에 저장해서 쓰기] 저장본에서 브라우저 확장 프로그램이 끼워 넣은 스크립트를 지움.

## 여러 교과 원안 형식(v1.9~)
- `[서답형 1-3]` 같은 서답형 지문 묶음 머리, 선택형·서답형이 섞여 나오는 순서(영어 등)를 인식. 서답형 표시가 있는 원안에서는 표 안의 `2. …` 목록 번호를 문항으로 보지 않음.
- 표·<보기> 안의 `1)`·`(1)`, 답 쓰는 빈 줄 `(1)      `, 표 밖의 답 칸 `①`은 소문항으로 보지 않음(발문일 때만 소문항).
- `[각 n점]`만 있으면 빈칸 `(      )` 수로 배점 계산. 소문항 번호 겹침((1) 다음 (1)) 알림.
- 채점기준표: 소문항 칸 없이 답안 칸 맨 앞에 `(1)`을 쓴 표. 답안지: `(2)` 아래 `1) 2)` 한 단계 더 들어간 줄, '배점' 머리글 아래 소문항 배점 칸과 문항 배점 칸이 따로 있는 표.
- 묶음 지문(작품 원문) 안의 낱말은 오타 후보로 알리지 않음.

## HWP 직접 읽기(v2.0~)
- HWP 5.0 파일을 변환 없이 읽음(`src\hwp.js`). 파일 첫 바이트로 HWP(OLE 복합 문서)와 HWPX(ZIP)를 가려 같은 문서 모양(문단·글자 모양·표·머리말/각주/글상자 구분·그림)으로 만듦. 외부 라이브러리 없이 브라우저 내장 압축 해제만 씀.
- 한글이 압축 끝 뒤에 여분 바이트를 붙이면 브라우저가 마지막 부분을 버리므로, 압축이 끝나는 위치를 찾아 다시 풂.
- 바탕쪽 글자, 표 캡션은 HWPX 읽기와 같이 본문에서 뺌.
- 문서 암호 HWP, 배포용 HWP, 보안(DRM) 표시 HWP, HWP 3.0 이하는 각각 해결 방법을 안내.

## v2.1
- 빈칸 두 칸 검사: 수식은 앞뒤에 빈칸을 붙여 읽으므로 수식을 □ 한 글자로 바꿔 검사(수식 옆 정상 띄어쓰기를 잘못 지적하던 문제).
- 답안지: 한 표를 좌우로 나눠 '문항·답란·배점'이 두 번 이상 나오면 묶음마다 따로 읽음(오른쪽 묶음 문항의 배점을 못 읽고 소문항이 왼쪽 문항에 섞이던 문제).

## v2.2
- 점검 결과 요약: 난이도 비율(왼쪽)·내용 영역별 분포(오른쪽)를 2단으로 표시(`sum-2col`, 좁은 화면은 한 단). 둘 중 하나만 있으면 한 단.

## v2.3
- 그림 판독성 검사가 실행마다 흔들리지 않게 함: 등사 흉내 잡티는 그림마다 고정된 씨앗의 무작위 값, 캔버스는 `willReadFrequently`(CPU)로 그림.
- 자동 비교 도구(앱 폴더의 test, 이 저장소에는 올리지 않음): 모은 시험 파일 전체를 다시 점검해 저장된 정답 결과와 달라진 곳만 보여 줌. 양식 해석을 고친 뒤에는 꼭 돌려 다른 양식이 깨지지 않았는지 확인.
