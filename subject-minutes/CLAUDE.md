# 학기말 교과협의록 앱 (subject-minutes)

교과 교사가 학기말 교과협의록(인정점 부여)을 작성해 평가부장에게 보내고, 평가부장(구인회 선생님)이 모아서 확인·인쇄하고 **학기말 인정점 부여표**를 만드는 앱입니다.

- 주소: `https://kuinhwoi.github.io/office-apps/subject-minutes/`
  - 교사용: `?api=<Apps Script 주소>`
  - 평가부장용: `?admin&api=<Apps Script 주소>`
- 파일: `index.html` 하나 (화면 전체)
- 서버: 선생님 구글 시트 '활천중 교과협의록 자동 작성 웹앱'에 붙은 Apps Script(`Code.gs`). **`Code.gs`는 이 저장소에 없습니다.**

## 구조
- 교사 화면: ① 기본 정보 → ② 대상 없음 체크 → ③ 나이스 수행평가 결시생 명단 가져오기 → ④ 수행평가 인정점 → ⑤ 정기시험 인정점 → ⑥ 논의 사항·기타 → ⑦ 증빙자료 첨부 → 인쇄 / 보내기. 오른쪽에 협의록 미리보기(한글 양식 모양).
- 평가부장 화면(비밀번호 필요): ① 제출 현황 ② 결시생 명단 ③ 인정점 부여표 ④ 설정
- 협의록 양식은 활천중학교 한글(hwpx) 협의록과 인정점 부여표를 그대로 본떴습니다. 표 모양이나 문구를 바꿀 때는 원래 양식과 맞는지 먼저 생각합니다.

## 서버(Code.gs)와 자료
- 모든 요청은 `fetch(API_URL, {method:'POST', body: JSON 문자열})`로 보냅니다.
- 시트의 '데이터' 탭에 `키 | 내용(JSON) | 저장 시각`으로 저장합니다. 주요 키:
  - `config`: 교과·참가교사·수행평가 영역·일정·규정 문구·교사 화면 학기(curSem)
  - `minutes|학년도|학년|학기|교과`: 제출된 협의록 (`attachments`에 증빙자료 목록)
  - `absent|학년도|학년|학기`: 수행평가 결시생 명단 (교사 화면 ＋ 버튼)
  - `exams|학년도|학년|학기`: 평가부장이 입력한 정기시험 결시생
- 증빙자료 파일은 선생님 구글 드라이브의 '교과협의록 증빙자료' 폴더에 저장합니다.
- 평가부장 비밀번호는 스크립트 속성 `ADMIN_PW`에 있습니다. 비밀번호 없이 되는 것은 `config`·`absent|`·`minutes|` 읽기, 협의록 제출, 증빙자료 올리기뿐입니다.
- **`Code.gs`를 고치면** 선생님께 파일을 드리고 다음을 안내합니다: 붙여넣기 → 저장 → (새 권한이 필요하면 `setup` 실행해 승인) → 배포 → 배포 관리 → 연필 → 새 버전 → 배포. 화면만 고친 경우에는 Apps Script를 손대지 않아도 된다고 알립니다.

## 겪었던 문제 (다시 하지 말 것)
- **파일 올리기에 XMLHttpRequest의 upload 진행 이벤트를 쓰지 않습니다.** 브라우저가 사전 확인(preflight) 요청을 보내는데 Apps Script가 받지 못해 "서버에 연결하지 못했습니다"가 났습니다. 반드시 `fetch`를 쓰고, 진행률은 예상치로 채웁니다.
- **설정 저장이 서버의 설정을 덮어쓴 적이 있습니다.** 새 컴퓨터에서 로그인한 뒤에도 설정 화면이 빈 기본값으로 남아 있었기 때문입니다. 지금은 로그인 뒤 설정 화면을 다시 채우고, 저장 전에 서버 설정과 비교합니다. 이 확인은 없애지 않습니다.
- 교사 화면은 작성 중인 내용을 브라우저(localStorage)에 기억합니다. 그래서 학기 같은 값은 화면을 열 때 설정(curSem)으로 다시 맞춥니다.

## 테스트 방법
- Apps Script를 흉내 내는 Node 서버에 `Code.gs`를 그대로 불러와 돌립니다. SpreadsheetApp·DriveApp·PropertiesService·Utilities를 흉내 내고, OPTIONS 요청에는 405를 돌려줘서 Apps Script처럼 만듭니다.
- Playwright로 교사 화면 작성 → 보내기 → 평가부장 화면 확인·부여표 생성까지 직접 눌러 봅니다.
- 나이스 엑셀(결시생명단, 수행평가 학급별 일람표)과 PDF 증빙자료는 선생님이 주신 실제 형식으로 시험합니다. 테스트용 실제 파일은 저장소에 올리지 않습니다.
- 엑셀은 SheetJS(cdn.sheetjs.com), PDF 묶기는 pdf-lib(cdn.jsdelivr.net)를 씁니다. 테스트할 때는 npm 패키지로 대신 넣습니다.

## 용어
- 인정 사유: 질병결, 미인정결, 인정결, 전입, 기타
- 미인정결 부과 방법: "최하점의 -1점"(표에는 이 문구, 부여 사유에는 규정 문장 그대로), "기본점수의 -1점"(기본점수 = 모든 채점요소 최하점의 합, 협의록에는 원래 문구)
- 학번 = 학년 + 반 + 번호 두 자리 (3학년 3반 5번 → 3305)
